# ReachPilot data connector policy

## YouTube
Use official YouTube Data API v3 for search, video metadata, statistics and region charts. API credentials remain server-side.

## Instagram / Facebook
Use Meta-authorized APIs and connected-account analytics where available. Never represent web scraping or third-party samples as complete Instagram/Facebook platform data.

## Google
Use legitimate Google trend/search datasets as available. Store source, observed_at, geography and confidence with each trend signal.

## AI
AI interprets collected evidence. AI does not invent the underlying trend. Every trend record should retain source provenance.

## Unified trend model
Each future signal should include platform, source, topic, observed_at, geography, language, metrics, velocity, confidence and evidence links.
