# ReachPilot AI
AI growth intelligence for creators and businesses.

## Android foundation
- Dark UI based on the approved ReachPilot mockup
- Home opportunity dashboard
- Separate platform workspace
- Instagram / YouTube / Facebook / Google / LinkedIn / Pinterest / X / WhatsApp / Website entry points
- Trend details with evidence-first design
- Trend Content Explorer for discoverable reels/videos
- AI Create workflow
- Analytics, Creator DNA and Growth Coach foundation
- GitHub Actions APK build

## Data integrity
Production trend cards must be backed by authorized APIs, connected-account analytics, or clearly labelled public/third-party signals. ReachPilot must not invent trends.
